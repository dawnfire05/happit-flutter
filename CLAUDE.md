## Architecture

**Feature-first + Clean Architecture**

```
lib/
├── main.dart                   # Entry point: configureDependencies() → runApp()
├── app/
│   ├── app.dart                # MaterialApp.router + global BlocProviders (AuthBloc, HabitListBloc)
│   ├── app_bloc_observer.dart
│   ├── di/
│   │   ├── get_it.dart         # DI setup: Dio (with dotenv SERVER_URL), FlutterSecureStorage
│   │   ├── get_it.config.dart  # generated by injectable_generator
│   │   └── authorize_interceptor.dart  # JWT Bearer token + auto-refresh on 401
│   └── modules/
│       ├── auth/               # Login, signup, token management
│       ├── habit/              # Habit CRUD + record tracking
│       ├── profile/            # User profile display
│       ├── splash/             # Auth state check on app start
│       └── common/             # Shared widgets (HappitAppBar, HappitBottomNavigationBar, MainButton)
├── routes/                     # go_router with TypedGoRoute annotations
│   ├── routes.dart             # GoRouter instance + part file declarations
│   ├── main_routes.dart        # Shell route (bottom nav layout)
│   ├── habit_routes.dart
│   ├── auth_routes.dart
│   └── spash_routes.dart
└── values/
    └── palette.dart
```

Each module follows this layer structure:
```
modules/<feature>/
├── data/
│   ├── model/      # freezed + json_serializable models
│   └── repository/ # retrofit abstract classes (generates .g.dart)
└── presentation/
    ├── bloc/       # flutter_bloc + freezed events/states
    ├── screen/     # UI only, no business logic
    └── widget/     # reusable widgets within the feature
```

## Key Patterns

**State management**: BLoC (`flutter_bloc`) with `freezed` sealed classes for events/states. `AuthBloc` and `HabitListBloc` are global (provided in `app.dart`). Feature-specific blocs are provided locally via `BlocProvider` in the screen.

**DI**: `get_it` + `injectable`. Annotate with `@injectable`, `@singleton`, `@lazySingleton`. After changing constructor parameters, run build_runner to regenerate `get_it.config.dart`.

**Networking**: Retrofit abstract class (`@RestApi`) + Dio singleton. Base URL comes from `.env` → `SERVER_URL`. `AuthorizeInterceptor` attaches Bearer token from `flutter_secure_storage` and handles 401 token refresh automatically.

**Models**: Use `freezed` (not `Equatable`) for all immutable objects. Models requiring JSON serialization use both `@freezed` and `@JsonSerializable` (generates `.freezed.dart` + `.g.dart`).

**Routing**: `go_router` with typed routes (`TypedGoRoute`, `TypedShellRoute`). Route classes are defined via annotations in separate `*_routes.dart` part files. After modifying route annotations, run build_runner.

**Auth flow**: `SplashScreen` → listens to `AuthBloc` state → `authenticated(UserModel)` → `HabitListRoute`, `unauthenticated` → `SignInRoute`.

## Code Generation

Three generators are used together:
- `injectable_generator` → `lib/app/di/get_it.config.dart`
- `retrofit_generator` → `lib/app/modules/**/data/repository/*.g.dart`
- `freezed` + `json_serializable` → `*.freezed.dart`, `*.g.dart`
- `go_router_builder` → `lib/routes/routes.g.dart`

Generated files are excluded from `flutter analyze` (configured in `analysis_options.yaml`).

## Environment

Requires `.env` file in project root with `SERVER_URL=...`. The file is declared as a Flutter asset and loaded via `flutter_dotenv`.

## Dependency Notes

- `go_router_builder` is pinned to `>=2.7.1 <2.9.0` — version 2.9.0+ expects `TypedGoRoute.caseSensitive` which is only available in go_router 15+.
- SSL certificate validation is disabled in Dio for development (`badCertificateCallback = true`).
